# Review regression fixtures

`large-vector-v10.hic` is an independent byte-level fixture: chrA has 70,000,000
BP bins at resolution 1, one count of 5 at (0,0), and VC divisors of 2 in
65,536-element Zstandard chunks. It advertises no VC_SQRT capability. Run
`python3 generate_review_vector.py /path/to/straw/C++/tests` to regenerate it.
The regression runs in a 128 MB heap; normalized queries must read only the
required pages rather than allocate the 560 MB decoded vector.

`score-order-v10.hic` is generated by `generate_review_score.cpp`, linked against
the hictools-c V10 writer and its normal dependencies.
Pass the output filename as the only argument. At source resolution 10,000,
its trans cells in coordinate order are (0,0)=2^60, (501,0)=-2^60, (0,1)=1,
spread across two source blocks. Deriving resolution 10,000,000 must produce 1.
Summing in block traversal order instead produces 0. The test checks regional
queries and iterators.

For a CMake hictools-c build at `$BUILD`, the score generator can be linked with:

```sh
c++ -std=c++17 -I/path/to/hictools-c generate_review_score.cpp \
  "$BUILD/v10/CMakeFiles/hic_v10.dir/writer.cpp.o" -lzstd -lz -o generate-review-score
./generate-review-score score-order-v10.hic
```

Add the Zstandard include/library search paths if it is installed outside the
compiler's default paths.
